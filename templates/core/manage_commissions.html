ℹ️ À propos des Commissions

Les commissions sont calculées automatiquement basées sur:

  • Les frais collectés - Basés sur le tarif de transaction
  • Le taux de commission - Pourcentage configuré pour chaque agent
  • Le type d'opération - Uniquement sur les TRANSFERTS, pas les RETRAITS

Formule: Commission = Frais Collectés × (Taux de Commission / 100)
